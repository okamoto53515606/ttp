TeraTerm Menu と TTP の違い

TeraTerm Menu は Tera Term のインストーラに同梱されている、常駐型の接続先ランチャーです。 「接続先を一覧から選んでログインする」という目的は TTP と同じですが、 設定と認証情報をどこに置くかが大きく違います。

TeraTerm Menu とは

  • Tera Term に同梱される接続先ランチャー。タスクトレイに常駐します
  • 登録した接続先を選ぶだけで、Tera Term を起動して自動ログインします
  • Tera Term 5.7.0 では TeraTerm Menu v1.24 が同梱されています（2026年9月）
  • 設定は既定でレジストリ（HKEY_CURRENT_USER\Software\ShinpeiTools\TTermMenu）に保存され、ポータブル版では ttpmenu.ini も使えます

Tera Term を既に使っているなら、追加インストールなしで使えるのが利点です。

同じところ

  • 接続先を一覧から選んで接続できる
  • Tera Term 本体を置き換えない（別のターミナルソフトを覚え直さなくてよい）
  • インストール作業がほぼ不要

違うところ

TeraTerm Menu と TTP の比較（2026年11月時点）
項目 TeraTerm Menu TTP
入手方法Tera Term に同梱単体配布（zip）
設定の保存先レジストリ ／ ttpmenu.iniアプリのフォルダ内（ttp_data）
認証情報の暗号化公式情報に記載なしAES-256
接続ログの自動取得×○（接続のたびに生成）
レジストリ不使用設定次第○
秘密鍵の指定外部ファイルを指定パスを登録（鍵ファイルは暗号化・コピーしない）
踏み台の多段接続マクロ側の記述による設定項目で対応
AWS SSM / ECS Exec 接続×○
アンインストールレジストリの後始末が必要フォルダ削除のみ

※ TeraTerm Menu の仕様は Tera Term の公式マニュアル（インストール／アンインストール手順）の記載に基づきます。 暗号化の有無について公式に明記が見当たらないため「記載なし」としています。

TeraTerm Menu で足りる人

  • 接続先が数台で、増える予定もない
  • 端末は自分専用で、他の人と設定を共有しない
  • パスワードは保存せず、接続のたびに入力している
  • 作業ログは必要になったときだけ手動で取っている

この条件に当てはまるなら、同梱の TeraTerm Menu で十分です。無理に置き換える必要はありません。

TTP が要る人

  • 接続先が増えてきて、どれが現役か分からなくなってきた
  • 端末を複数人で使う、または設定を配っている
  • レジストリに接続先や認証情報を置きたくない
  • 作業ログを「確実に」残す必要がある
  • AWS の EC2 / Fargate にも同じ入口から入りたい

併用できるか

技術的には併用できます。TTP はレジストリを使わないため、TeraTerm Menu の設定に影響しません。ただし同じ接続先を二重に管理することになるため、移行するなら片方に寄せたほうが運用は楽になります。

Tera Term 5 で LogMeTT が使えなくなった場合。 Tera Term 5.0 で LogMeTT と TTLEditor はインストーラから削除されました。詳しくは LogMeTT からの移行をご覧ください。

比較 LogMeTT は Tera Term 5.0 で削除されました 比較 RLogin と TTP は、競合しません
