# TTP v1.2.0

AWS の **Session Manager（SSM）** と **ECS Exec** に対応しました。
sshd もインバウンドポートの開放もなしで、EC2 と Fargate のシェルに入れます。

## 追加

### AWS から接続（SSM / ECS Exec）

- メニュー「AWS」→「AWS から接続...」（`Ctrl+Shift+A`）で、**いま接続できる** EC2 と Fargate タスクを一覧表示
  - EC2: SSM エージェントが `Online` のものだけ
  - ECS: ECS Exec が有効で `ExecuteCommandAgent` が `RUNNING` のもの
- 一覧からダブルクリックで、Windows Terminal のセッションを起動
- EC2 / ECS（クラスタ → サービス → タスク）のツリー表示
- 検索、「接続可能のみ」フィルタ、`F5` 更新
- **自動更新（30秒）** でサービスのタスク入れ替わりに追従
- ECS タスクは **起動日時の新しい順** に表示
- 接続できない対象はグレー表示し、非表示件数と理由をステータスバーに表示

### 認証設定

- 設定は **アクセスキー・シークレット・リージョン** の 3 つだけ
- マスターパスワード由来の鍵で暗号化して保存（`ttp_data/aws.enc`）
- **MFA 対応（任意）**: MFA 必須の IAM ユーザーだけチェックを入れる方式。
  6 桁コードを入力し、約 12 時間キャッシュ。MFA を使わないユーザーは入力不要
- **AWS CLI は不要**。Session Manager プラグインだけで動作
  （AWS CLI がインストールされている場合はフォールバックとして使用）

## 改善

- マスターパスワード変更時に AWS 設定も再暗号化
- 必要なツールが見つからない場合、インストール案内のポップアップを表示
  （ダウンロードページを開くボタン付き）

## 注意

- 接続には **Session Manager プラグイン** が必要です（TTP には同梱していません）
- 初回起動時に Microsoft Defender SmartScreen の警告が出る場合があります
  → 「詳細情報」→「実行」で起動できます
- ECS Exec は既存タスクに後付けできません（新規起動分から有効）
- セッションは 20 分のアイドルタイムアウトがあります

## インストール

1. 下の `ttp-1.2.0.zip` をダウンロード
2. 任意のフォルダに解凍
3. `ttp.exe` を実行

既存の `ttp_data/` と `logs/` はそのまま引き継げます。

**フルチェンジログ**: https://github.com/okamoto53515606/ttp/compare/v1.1.0...v1.2.0
