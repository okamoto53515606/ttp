セキュリティ修正と、同梱 Python の更新を含むパッチリリースです。
機能の追加・変更はありません。

## セキュリティ

### 依存パッケージの脆弱性修正

`cryptography` 46.0.5 に 11 件の勧告が検出されたため、**50.0.2** に更新しました。

- PYSEC-2026-3552 / 3553 / 3554（修正: 49.0.0 / 50.0.0）
- GHSA-537c-gmf6-5ccf（修正: 48.0.1）
- PYSEC-2026-35 / 36

あわせて `cffi` / `pycparser` / `PyInstaller` なども最新化しています。
更新後、`pip-audit` で **既知の脆弱性 0 件** を確認済みです。

### CVE-2026-115557（eMudhra / emSign 中間 CA の鍵問題）

2026 年 10 月に公表された、インドの認証局 eMudhra が発行した中間 CA 証明書の
秘密鍵が復元可能だった問題です。TLS 通信の偽装（MITM）に悪用される可能性があります。

TTP への影響を次のとおり確認しました。

| 確認項目 | 結果 |
|---|---|
| 通信先 | AWS エンドポイントのみ（boto3） |
| CA バンドル | `certifi` は不使用。`botocore` 同梱の CA バンドルを使用 |
| 同梱バンドルの内容 | 126 証明書。**eMudhra / emSign のエントリは 0 件** |

そのため、現時点で TTP は問題の認証局を信頼していません。

## アップデート方法（既存ユーザー向け）

**既存の ttp フォルダに上書き**してください。
フォルダを移動・リネームすると、ログ保存先などの設定（絶対パス）が引き継げません。

1. TTP を終了する
2. 必要に応じて、現在の ttp フォルダを丸ごとコピーしてバックアップする
3. `ttp-1.2.1.zip` を展開する
4. 展開した中の **`ttp.exe` と `_internal` フォルダ** を、既存の ttp フォルダへ上書きコピー
5. `ttp.exe` を起動する

> `ttp_data/`（接続設定・暗号化データ）と `logs/` は上書きしないでください。
> そのまま残せば、接続先やマスターパスワードを再設定せずに済みます。
> 展開したフォルダごと置き換えると `logs/` が消えるので注意してください。

## インストール（初めての方）

1. 下の `ttp-1.2.1.zip` をダウンロード
2. 任意のフォルダに解凍
3. `ttp.exe` を実行

初回起動時に Microsoft Defender SmartScreen の警告が出る場合があります
（「詳細情報」→「実行」）。
